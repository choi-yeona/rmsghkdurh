# 📐 수렴반경 탐험기

매끈한 함수 1/(1+x²)의 테일러 급수는 왜 어떤 구간에서만 수렴할까?

**가설**: 수렴반경은 전개 중심 a에서 복소평면의 특이점 x = ±i 까지의 거리, 즉 R(a) = √(a² + 1).

이 앱은 가설을 수치로 검증하고 시각화합니다.

## 화면 구성

| 탭 | 내용 |
|---|---|
| ① 실수 그래프 | 부분합 곡선과 이론상 수렴 구간 |
| ② 복소평면 | 중심에서 ±i 에 닿는 원 (반지름 = 수렴반경) |
| ③ x₀에서의 수렴 | 한 점에서 부분합과 오차가 항마다 줄어드는(늘어나는) 비율 |
| ④ 수렴반경 검증 | 계수에서 추정한 R vs 이론값 √(a²+1) |
| ⑤ 해설 | 수식 유도와 결과 읽는 법 |

## 계산 방법 요약

- 계수 점화식: (1+a²)cₙ + 2a·cₙ₋₁ + cₙ₋₂ = 0
- 특성방정식 (1+a²)r² + 2ar + 1 = 0 의 근 r = (−a ± i)/(1+a²), |r| = 1/√(1+a²)
- 검증용 닫힌 식: cₙ = (−1)ⁿ · Im[1/(a−i)ⁿ⁺¹]
- 수렴반경 추정: R ≈ 1 / max |cₖ|^(1/k)  (마지막 12개 항)
